# Security Policy

## Reporting a vulnerability

Please report security issues **privately** through GitHub's private security
advisories: open the repository's **Security** tab and click **Report a
vulnerability**. Do not open a public issue for security reports.

## Scope

This repository is **course content** (Markdown lessons, exercises, and
examples) that teaches OpenCode. It ships no production code and runs no hosted
service, so most reports will not apply here.

Reports that are relevant to this repository include:

- Secrets or API keys accidentally committed to the repository
- Malicious or unsafe instructions/commands in lessons or examples

Security issues in the OpenCode tool itself are out of scope for this
repository and should go to the upstream project:
<https://github.com/anomalyco/opencode/issues>.

## Supported versions

Only the **latest release** of this repository receives fixes. Corrections are
made on the `main` branch and included in the next release.

## What to expect

We aim to acknowledge a report within a few days and will keep you updated as we
investigate. To help us, please include a clear description, the affected file
or link, and the steps needed to reproduce the issue.
