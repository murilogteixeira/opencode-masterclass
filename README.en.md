## What is this?

**OpenCode** is an open source **AI coding agent** that runs in your terminal (TUI), desktop and web. This repository is a progressive, project-based **course/guide** that teaches you to master it end to end. Every lesson has an objective, content, a **hands-on challenge**, and links to the [official documentation](https://opencode.ai/v2/docs/).

## Who is it for?

- Developers new to OpenCode who want a structured path (Module 01 → 06)
- Teams adopting an AI coding agent and needing **agents, permissions, policies, and CI/CD** patterns
- Builders integrating OpenCode via **HTTP API, JavaScript client, and SDK**

## Quick start

```bash
git clone https://github.com/murilogteixeira/opencode-masterclass.git
cd opencode-masterclass

# Install OpenCode V2
curl -fsSL https://opencode.ai/v2/install | bash

# Connect a provider and pick a model
opencode   # then run: /connect  and  /models
```

Then follow the modules in order — the lessons are in Portuguese, each ending with a practical challenge.
