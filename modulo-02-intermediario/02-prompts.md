# 02. Prompts Avançados e Templates

## 🎯 Objetivo
Criar prompts estruturados que produzem resultados consistentes com o OpenCode.

## 📋 Conteúdo

### Template básico

```markdown
Contexto: {contexto}
Instrução: {instrução}
Formato de saída: {formato}
```

### Dica de ouro
- Seja específico com o formato esperado
- Forneça exemplos (few-shot prompting)
- Defina restrições claras
