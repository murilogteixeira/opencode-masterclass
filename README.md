# Curso Masterclass de OpenCode: Do Básico ao Avançado

Bem-vindo(a) ao **OpenCode Masterclass** — um curso prático, progressivo e baseado na documentação oficial que te leva da instalação do OpenCode até automação com agentes customizados, workflows em CI e integração via API/SDK.

> **Fonte da verdade:** toda aula referencia a [documentação oficial V2](https://opencode.ai/v2/docs/). Se algo parecer desatualizado, confira lá primeiro.

## 📖 O que este curso oferece

| Nível | Módulo | Aulas | Foco |
|------|--------|-------|------|
| 🟢 **Básico** | Módulo 01: Fundamentos e Configuração | 2 | O que é o OpenCode, instalação, TUI, `run`, autenticação, `opencode.json` |
| 🔵 **Intermediário** | Módulo 02: Integração de APIs, Prompts e Dados | 3 | Chamadas de API, MCP servers, prompts e instruções de projeto, dados |
| 🟠 **Avançado** | Módulo 03: Automação e Agentes Customizados | 3 | Agentes Markdown, slash commands, CI/CD com `opencode run`, permissões |
| 🟣 **Especialista** | Módulo 04: Projetos Finais e Otimização | 3 | Projeto capstone, otimização de contexto/custo, deploy e integração |

**Formato:** cada aula gera arquivos `.md` e código-fonte prontos para commit. Aprenda criando, não apenas lendo!

## 🚀 Como usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/murilogteixeira/opencode-masterclass.git
   cd opencode-masterclass
   ```
2. **Siga as aulas na ordem** — os módulos são progressivos e cada um assume o anterior.
3. **Faça o desafio prático** ao final de cada aula antes de avançar.
4. **Versione seu progresso** — commit pequeno por aula facilita revisar e reverter.
