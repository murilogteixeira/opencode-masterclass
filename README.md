# Curso Masterclass de OpenCode: Do Básico ao Avançado

Bem-vindo(a) ao **OpenCode Masterclass** — um curso prático, progressivo e pronto para produção que te leva da instalação básica do OpenCode até a automação de ponta com agentes personalizados e otimização de performance.

## 📖 O que este curso oferece

| Nível | Módulo | Aulas | Skill focus |
|------|--------|-------|-------------|
| 🟢 **Básico** | Módulo 01: Fundamentos e Configuração | 2 | Introdução, instalação, primeiros comandos no terminal |
| 🔵 **Intermediário** | Módulo 02: Integração de APIs e Dados | 3 | Chamadas de API, prompts avançados, processamento de dados Python/JS |
| 🟠 **Avançado** | Módulo 03: Automação e Workflows de Agentes | 3 | Agentes personalizados, CI/CD, orquestração de workflows, padrões |
| 🟣 **Especialista** | Módulo 04: Projetos Finais e Performance | 2 | Projeto capstone, profiling, escalabilidade, melhores práticas |

**Formato:** Cada aula gera arquivos .md e código fonte prontos para commit. Aprenda criando, não apenas lendo!

## 🚀 Como usar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/murilogteixeira/opencode-masterclass.git
   cd opencode-masterclass
   ```
2. **Siga as aulas na ordem** — elas estão organizadas por módulos para evolução progressiva.
3. **Conclua cada módulo** — edite os arquivos, adicione suas soluções e versiones ao longo do caminho.
4. **Finalize o projeto** (Módulo 04) e faça um pull request com suas mudanças!
